## Step 1. 지난 글 고민점 짚고 가기

### ① 19세 비율, 바뀌면 결과도 바뀔까?

2편에서 15~19세 묶음을 나눌 때, 19세 비율(21.7%)을 통근·통학자가 아닌
전체 인구**로 구했어요.
<br> 실제 통근·통학자 중 19세 비율은 이것과 다를 수 있어요. 
그래서 비율이 달라지면 청소년 수가 얼마나 바뀌는지 직접 확인해 봤어요.

```python
teen_14 = by.loc[("남자", "12~14세")].sum() + by.loc[("여자", "12~14세")].sum()
teen_1519 = by.loc[("남자", "15~19세")].sum() + by.loc[("여자", "15~19세")].sum()
total = by.values.sum()

for r in [0.10, 0.15, 0.20, 0.217, 0.25, 0.30]:
    teen = teen_14 + teen_1519 * (1 - r)
    print(f"19세 비율 {r:.1%} → 100명 중 청소년 {teen / total * 100:.1f}명")
```
> **코드 설명**
> <br>
> - by 는 2편에서 만든 "성별 × 나이대 × 교통수단" 표예요. by.loc[("남자", "12~14세")] 로 그 줄을 꺼내고 .sum() 으로 교통수단을 다 더하면 그 집단의 통근·통학자 수가 돼요.
> - teen_14 는 12~14세, teen_1519 는 15~19세 통근·통학자 수(남녀 합)예요.
> - for r in [...* 는 19세 비율을 10%부터 30%까지 바꿔 가며 반복해요.
> - teen_14 + teen_1519 × (1 − r) 은 청소년 수, 이걸 전체로 나누고 100을 곱하면 100명 중 몇 명인지 나와요.
> - f"{r:.1%}" 는 0.217을 "21.7%"처럼 퍼센트로 보여주는 글자 서식이에요.

![](/assets/img/20261006-capture-5.png)


19세 비율이 약 10%~24%*사이면 반올림해서 청소년은 10명 그대로예요.
<br> 그리고 19세는 고등학교를 졸업하고 쉬는 사람도 있어서, 
통근·통학자 중 19세 비율은 오히려 21.7%보다 낮을 가능성이 커요.
그러니 10명으로 정한건 19세 비율을 통학.통근자가 아닌 전체 인구로 해도 큰 문제가 없다고 생각했습니다.

## Step 2. 페르소나에서 성인 90명 뽑기

### 송파구 페르소나에 나이대 붙이기

먼저 송파구 페르소나에 2편과 똑같은 나이대 이름표를 붙여요. 이름표가 같아야 명단과 짝을 맞출 수 있거든요.

```python
from datasets import load_dataset

ds = load_dataset("nvidia/Nemotron-Personas-Korea", split="train")
df = ds.to_pandas()
seoul = df[df["province"].str.contains("서울")].copy()
print(len(seoul))

songpa = seoul[seoul["district"] == "서울-송파구"].copy()
songpa["나이대"] = pd.cut(songpa["age"],
                        bins=[19, 30, 40, 50, 60, 70, 200],
                        labels=["19~29세", "30대", "40대", "50대", "60대", "70세 이상"],
                        right=False)

pool = pd.crosstab(songpa["나이대"], songpa["sex"])
print(pool)
```
> **코드 설명**
> <br>
> - seoul 은 서울 페르소나 표예요. 여기서 송파구만 골라 **songpa** 에 저장해요.
> - pd.cut(나이, bins=[...], labels=[...]) : 나이를 구간으로 잘라서 이름표를 붙여요. 19~29세는 19 이상 30 미만, 30대는 30 이상 40 미만 …
> - right=False : 는 구간의 오른쪽 끝을 포함하지 않는다는 뜻이에요. 30세는 "19~29세"가 아니라 "30대"로 들어가요.
> - pd.crosstab(행, 열) 으로 나이대 × 성별 칸마다 후보가 몇 명인지 세요.

![](/assets/img/20261006-capture-6.png)

칸마다 후보가 수백 명씩 있어서, 가장 많이 뽑아야 하는 칸
(30대·40대 남자 12명)도 아주 매우 충분합니다.

### 칸마다 무작위로 뽑기

2편에서 만든 명단(`songpa_100.csv`)을 불러와서, "페르소나" 칸마다 같은 나이대·성별의 송파구 페르소나를 무작위로 뽑아요.

```python
people = pd.read_csv("songpa_100.csv", index_col="번호")
adults = people[people["출처"] == "페르소나"]

picked = []
for (age, sex), group in adults.groupby(["나이대", "성별"]):
    cand = songpa[(songpa["나이대"] == age) & (songpa["sex"] == sex)]
    chosen = cand.sample(n=len(group), random_state=42)
    chosen.index = group.index
    picked.append(chosen)

adult_df = pd.concat(picked)
adult_df["나이대"] = adults["나이대"]
adult_df["교통수단"] = adults["교통수단"]
adult_df["출처"] = "페르소나"
adult_df["이름"] = adult_df["persona"].str.extract(r"([가-힣]{2,4}) 씨", expand=False)

print(adult_df[["이름", "sex", "age", "나이대", "교통수단"]].head(10))
print("이름 못 찾은 사람:", adult_df["이름"].isna().sum())
```
> **코드 설명**
> <br>
> - pd.read_csv("songpa_100.csv", index_col="번호") 로 2편 명단을 불러오고, "번호"를 줄 이름으로 써요.
> - adults 는 그중 "페르소나"에서 뽑을 90명이에요.
> - adults.groupby(["나이대", "성별"]) 는 같은 나이대·성별끼리 묶어서 한 묶음씩 꺼내요. 예를 들어 ("30대", "남자") 묶음에는 12명이 들어 있어요.
> - cand 는 그 칸에 맞는 송파구 페르소나 후보예요.
> - cand.sample(n=..., random_state=42) 는 후보 중에서 필요한 인원만큼 무작위로 뽑아요. 
> - chosen.index = group.index 로 뽑힌 사람에게 명단의 번호를 붙여서, 명단의 교통수단과 짝을 맞춰요.
> - pd.concat(picked) 로 칸마다 뽑은 사람들을 위아래로 이어 붙여요.
> - 페르소나에는 이름 열이 따로 없어요. 대신 persona 글이 "홍길동 씨는 …"으로 시작해서, str.extract(r"([가-힣]{2,4}) 씨") 로 "씨" 앞의 한글 2~4글자를 꺼냈어요. 이런 글자 패턴을 **정규표현식**이라고 한답니다.

![](/assets/img/20261006-capture-7.png)


이렇게 "이름 못 찾은 사람: 0"이 나오면 90명 모두 이름까지 잘 뽑힌 거예요!

## Step 3. 청소년 10명 합성하기

페르소나에는 19세 미만이 없어서 청소년 10명은 직접 만들어야 해요.
<br> 기존 페르소나와 같은 열을 채우되 값마다 근거를 정했어요.

| 열 | 채우는 방법 | 근거 |
| --- | --- | --- |
| 성별, 교통수단 | 명단 그대로 | 2편 결과 |
| age | 12~18세 중 송파구 인구 비율대로 무작위 | KOSIS 1세 단위 인구 (DT_1PM2001) |
| education_level | 12세 초등학교, 13~15세 중학교, 16~18세 고등학교 | 같은 표에서 나이별로 가장 많이 다니는 학교 |
| marital_status | 미혼 | 송파구 15~19세는 100% 미혼 (DT_1PM2003) |
| occupation | 학생 | |
| 이름 | 송파구 젊은 페르소나의 성과 이름을 섞어서 새로 만들기 | 기존 데이터와 이름 스타일 맞추기 |
| family_type, housing_type | 송파구 19~20세 미혼 페르소나에서 무작위로 가져오기 | 청소년과 가장 비슷한 사람들의 가구 형태 |
| persona | 정해진 문장 틀에 값 끼워 넣기 | 기존 글처럼 "OOO 씨는 …"으로 시작 |

### ① 나이 · 학교 · 기본 정보

```python
import numpy as np
rng = np.random.default_rng(42)

teens = people[people["출처"] == "합성"].copy()
teens["sex"] = teens["성별"]

age_pop = {
    "남자": {12: 2780, 13: 3038, 14: 2589, 15: 2819, 16: 2859, 17: 3035, 18: 2812},
    "여자": {12: 2633, 13: 2869, 14: 2531, 15: 2403, 16: 2801, 17: 2656, 18: 2777},
}

def pick_age(sex):
    ages = list(age_pop[sex].keys())
    w = np.array(list(age_pop[sex].values()))
    return int(rng.choice(ages, p=w / w.sum()))

def school(age):
    if age == 12:
        return "초등학교"
    elif age <= 15:
        return "중학교"
    else:
        return "고등학교"

teens["age"] = [pick_age(s) for s in teens["sex"]]
teens["education_level"] = teens["age"].apply(school)
teens["marital_status"] = "미혼"
teens["military_status"] = "비현역"
teens["occupation"] = "학생"
teens["bachelors_field"] = None
teens["district"] = "서울-송파구"
teens["province"] = "서울"
teens["country"] = "대한민국"
teens[["sex", "age", "education_level"]]
```
> **코드 설명**
> <br>
> - rng = np.random.default_rng(42) : 무작위 숫자를 만드는 도구예요. 42로 고정해서 다시 돌려도 같은 결과가 나와요.
> - teens : 명단에서 "합성" 10명만 꺼낸 표예요. 기존 페르소나와 열 이름을 맞추려고 "성별" 을 "sex" 로도 복사했어요.
> - age_pop : 송파구 12~18세 1세 단위 인구예요. KOSIS 교육정도 표에서 가져왔어요.
> - pick_age(sex) : 그 인구 비율대로 나이를 하나 뽑아요. rng.choice(나이들, p=비율) 에서 p 는 각 나이가 뽑힐 확률이에요.
> - school(age) : 나이를 넣으면 다니는 학교를 돌려줘요. KOSIS 표를 보면 12세는 대부분 초등학교 6학년, 15세는 대부분 중학교 3학년이었어요. (인구총조사는 만 나이 기준)
> - 나머지 줄은 혼인상태, 병역, 직업, 지역처럼 모두 같은 값인 열을 한 번에 채워요. bachelors_field(대학 전공)는 해당이 없어서 None(빈칸)이에요.

### ② 이름 · 가구 형태 · 주거 형태

```python
young = seoul[seoul["age"] <= 24].copy()
young["이름"] = young["persona"].str.extract(r"([가-힣]{2,4}) 씨", expand=False)
young = young[young["이름"].str.len() == 3]

def make_name(sex):
    names = young.loc[young["sex"] == sex, "이름"]
    surname = names.sample(1, random_state=rng).iloc[0][0]
    given = names.sample(1, random_state=rng).iloc[0][1:]
    return surname + given

teens["이름"] = [make_name(s) for s in teens["sex"]]

ref = songpa[(songpa["age"] <= 20)
             & (songpa["marital_status"] == "미혼")
             & (songpa["family_type"].str.contains("부모|어머니|아버지"))]
print(ref["family_type"].value_counts())

home = ref[["family_type", "housing_type"]].sample(len(teens), replace=True, random_state=rng)
teens["family_type"] = home["family_type"].values
teens["housing_type"] = home["housing_type"].values
teens[["이름", "sex", "age", "family_type", "housing_type"]]
```
> **코드 설명**
> <br>
> - young : 서울 페르소나 중 24세 이하예요. 청소년과 나이가 가장 가까운 사람들이라 이름 스타일도 비슷할 거예요.
> - 페르소나에는 이름 열이 따로 없어서, persona 글의 "OOO 씨"에서 str.extract(r"([가-힣]{2,4}) 씨") 로 이름을 꺼내요. "씨" 앞의 한글 2~4글자라는 뜻의 **정규표현식**이에요. str.len() == 3 으로 세 글자 이름만 남겨요.
> - make_name(sex) : 같은 성별의 젊은 페르소나 두 명을 뽑아서, 한 명의 성(첫 글자, [0])과 다른 한 명의 이름(둘째 글자부터, [1:])을 합쳐요. 기존 데이터에 없는 새 이름이 되면서도 스타일은 비슷해요.
> - ref : 송파구 페르소나 중 20세 이하 · 미혼 · 부모와 사는 사람이에요. str.contains("부모|어머니|아버지") 는 가구 형태에 셋 중 하나라도 들어 있으면 남겨요. ( **|** 는 "또는")
> - ref[[...]].sample(len(teens), replace=True) 로 그중 10명의 가구 형태와 주거 형태를 한 사람 단위로 같이 가져와요. 따로 뽑으면 어색한 조합이 생길 수 있거든요. 
> - replace=True : 같은 사람이 두 번 뽑혀도 된다는 뜻이에요.

### ③ 소개 글 12개 + uuid

기존 페르소나에는 persona, professional_persona, sports_persona … 처럼 **소개 글이 12개**나 있어요. 청소년도 같은 열을 채워야 해서, 문장 틀에 값을 끼워 넣는 방식으로 만들었어요.

```python
import uuid

how = {"도보": "걸어서", "지하철": "지하철을 타고", "버스": "버스를 타고",
       "자전거": "자전거를 타고", "복합수단": "버스와 지하철을 갈아타며",
       "자차": "부모님 차를 타고", "기타": "다른 교통수단으로"}
student = {"초등학교": "초등학생", "중학교": "중학생", "고등학교": "고등학생"}

sports = ["축구", "농구", "배드민턴", "줄넘기", "수영", "자전거 타기"]
arts = ["웹툰 보기", "K-pop 듣기", "그림 그리기", "피아노 연주", "영화 보기", "댄스"]
skills = ["수학 문제 풀이", "영어 단어 암기", "코딩 기초", "악기 연주", "글쓰기", "발표"]
dreams = ["프로그래머", "선생님", "의사", "디자이너", "운동선수", "과학자", "요리사", "경찰관"]
foods = ["떡볶이", "치킨", "마라탕", "돈가스", "김치찌개", "라면"]
trips = ["제주도", "부산", "강릉", "경주", "여수"]

def pick(pool, k=1):
    return [str(x) for x in rng.choice(pool, size=k, replace=False)]

for i, row in teens.iterrows():
    name, age, st = row["이름"], row["age"], student[row["education_level"]]
    sport, art = pick(sports)[0], pick(arts)[0]
    skill = pick(skills, 2)
    dream, food, trip = pick(dreams)[0], pick(foods)[0], pick(trips)[0]

    teens.loc[i, "uuid"] = uuid.uuid4().hex
    teens.loc[i, "persona"] = f"{name} 씨는 서울 송파구에 사는 {age}세 {st}으로, 평소 {how[row['transport']]} 학교에 다닌다."
    teens.loc[i, "professional_persona"] = f"{name} 씨는 {row['education_level']}에 다니는 {st}으로, 수업과 숙제, 학원 일정으로 하루를 보낸다."
    teens.loc[i, "sports_persona"] = f"{name} 씨가 가장 좋아하는 운동은 {sport}이다."
    teens.loc[i, "arts_persona"] = f"{name} 씨는 쉬는 시간에 {art}로 스트레스를 푼다."
    teens.loc[i, "travel_persona"] = f"가족과 함께 간 {trip} 여행이 가장 기억에 남는다."
    teens.loc[i, "culinary_persona"] = f"좋아하는 음식은 {food}이고, 친구들과 학교 앞 분식집에 자주 들른다."
    teens.loc[i, "family_persona"] = f"{row['family_type']} 형태로 살며, 가족과 저녁을 함께 먹는 시간을 소중히 여긴다."
    teens.loc[i, "cultural_background"] = "서울 송파구에서 자라 학교와 학원을 오가며 또래 문화 속에서 생활하는 10대 학생이다."
    teens.loc[i, "skills_and_expertise"] = f"{skill[0]}와 {skill[1]}에 자신이 있다."
    teens.loc[i, "skills_and_expertise_list"] = str(skill)
    teens.loc[i, "hobbies_and_interests"] = f"취미는 {sport}, {art}이다."
    teens.loc[i, "hobbies_and_interests_list"] = str([sport, art])
    teens.loc[i, "career_goals_and_ambitions"] = f"장래 희망은 {dream}이며, 지금은 원하는 학교에 진학하는 것을 목표로 공부하고 있다."

print(teens.loc[1, "persona"])
print(teens.loc[1, "hobbies_and_interests_list"])
```
> **코드 설명**
> <br>
> - **import uuid** 는 겹치지 않는 아이디를 만드는 파이썬 기본 도구예요. **uuid.uuid4().hex** 는 기존 페르소나처럼 32자리 아이디를 만들어요.
> - **how** 는 교통수단을 문장에 넣기 좋은 말로, **student** 는 학교를 "중학생"처럼 바꾸는 사전이에요.
> - **sports, arts, skills …** 는 청소년이 가질 만한 운동, 취미, 특기, 장래 희망, 음식, 여행지 목록이에요. 제가 직접 골랐어요.
> - **pick(pool, k)** 는 목록에서 k개를 겹치지 않게 무작위로 골라요. **str(x)** 로 감싼 건 numpy 글자를 보통 글자로 바꾸려고요. (안 하면 목록에 `np.str_('축구')` 처럼 지저분하게 찍혀요)
> - **for i, row in teens.iterrows():** 로 10명을 한 명씩 돌면서, **teens.loc[i, "열 이름"] = ...** 으로 그 사람의 칸을 채워요.
> - **f"..."** 문장 틀의 **{ }** 자리에 그 사람의 이름, 나이, 학교, 교통수단 등이 들어가요.
> - **_list** 로 끝나는 열은 기존 데이터처럼 **['수영', 'K-pop 듣기']** 같은 목록 모양 글자로 넣었어요.

```
김OO 씨는 서울 송파구에 사는 17세 고등학생으로, 평소 걸어서 학교에 다닌다.
['수영', 'K-pop 듣기']
```

> 💡 문장 틀에 단어를 끼울 때 "을/를", "이/가" 같은 조사가 문제였어요. "축구를"은 되는데 "배드민턴를"은 틀리잖아요?
> <br> 그래서 **"좋아하는 운동은 {sport}이다"** 처럼 조사가 안 바뀌는 문장으로 바꿨어요.

```python
cols = list(seoul.columns) + ["age_group", "transport"]

residents = pd.concat([teens, adult_df]).sort_index()
residents["age_group"] = (residents["age"] // 10 * 10).astype(str) + "대"
residents = residents[cols]

residents.to_csv("songpa_residents_100.csv", index=False, encoding="utf-8-sig")
print(residents.shape)
print(residents[["sex", "age", "age_group", "transport"]].head(12))
```
> **코드 설명**
> <br>
> - **cols** 는 결과물의 열 순서예요. 원본 페르소나의 26개 열(**seoul.columns**) 뒤에 **age_group**, **transport** 를 붙였어요.
> - **pd.concat([teens, adult_df])** 로 청소년 10명과 성인 90명을 이어 붙이고, **.sort_index()** 로 번호 순서대로 정렬해요.
> - **age_group** 은 나이를 10으로 나눈 몫에 10을 곱해서 만들어요. 17 → 10 → "10대", 45 → 40 → "40대". **//** 는 나머지를 버리는 나눗셈이에요.
> - **residents[cols]** 로 결과물 열만, 정해진 순서대로 남겨요. "번호", "나이대", "이름" 같은 작업용 열은 여기서 빠져요.
> - **to_csv(..., index=False)** 로 번호 없이 저장해요. 엑셀이나 구글 시트에서 그대로 열 수 있어요.
