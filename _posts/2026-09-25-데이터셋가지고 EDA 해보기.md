이번 글에서는 NVIDIA가 공개한 한국어 합성 페르소나 데이터셋 **Nemotron-Personas-Korea**로 EDA(탐색적 데이터 분석)를 해보려고 합니다. 이번 1편에서는 Mac에서 PyCharm으로 분석 환경을 만들고, 데이터를 불러와 데이터프레임을 확인하는 과정까지 정리합니다.

### EDA란?
 **EDA(Exploratory Data Analysis, 탐색적 데이터 분석)** 는 모델을 만들거나 결론을 내리기 전에, 데이터를 여러 방향으로 살펴보며 구조와 특징을 파악하는 과정이에요.
데이터에 어떤 컬럼이 있는지, 결측치나 이상한 값은 없는지, 값들이 어떻게 분포하는지, 변수끼리 어떤 관계가 있는지를 통계량과 그래프로 확인합니다.

### 분석할 데이터: Nemotron-Personas-Korea
- **출처**: [Hugging Face – nvidia/Nemotron-Personas-Korea](https://huggingface.co/datasets/nvidia/Nemotron-Personas-Korea)
- **라이선스**: CC BY 4.0 (출처 표기 시 자유롭게 사용 가능)
- **규모**: 100만 명 × 26개 컬럼
- **특징**: 통계청(KOSIS), 대법원 등의 실제 인구 통계 분포에 맞춰** 성별·나이·학력·직업·지역을 뽑은 뒤, LLM으로 각 인물의 페르소나 문장을 생성한 **합성(가상) 데이터**예요.

참고: [PyTorchKR 소개 글](https://discuss.pytorch.kr/t/nemotron-personas-korea-nvidia/9908)

데이터 분석은 PyCharm에서 주피터 노트북으로 진행할 거예요.

### 1. PyCharm 세팅
1. **가상환경 켜기**<br>
   PyCharm에서 새 프로젝트를 만든 뒤, 아래쪽 Terminal에서 가상환경을 켜줍니다.

```bash
   source .venv/bin/activate
```
2. **패키지 설치**<br>
   프롬프트 앞에 `(.venv)`가 나온 걸 확인한 후 설치를 진행했어요.

```bash
   python -m pip install jupyter datasets pandas pyarrow matplotlib seaborn
```

   ![](/assets/img/20260925-capture-3.png)

4. **데이터 불러오기**<br>
   이제 데이터를 불러올게요. 저는 Mac 환경이라 그래프의 한글이 깨지지 않도록 폰트 설정도 같이 해줬어요.

```python
   import pandas as pd
   import matplotlib.pyplot as plt
   import seaborn as sns
   from datasets import load_dataset

   # Mac 한글 폰트 설정
   plt.rcParams["font.family"] = "AppleGothic"
   plt.rcParams["axes.unicode_minus"] = False   # 마이너스(-) 기호 깨짐 방지

   # 데이터 불러오기 (처음엔 약 2GB 다운로드)
   ds = load_dataset("nvidia/Nemotron-Personas-Korea", split="train")
   ds
```

   ![](/assets/img/20260925-capture-5.png)
   이렇게 분주하게 다운로드되는 모습!

   
   ![](/assets/img/20260925-capture-6.png)
   마지막에 이렇게 `num_rows: 1000000`이 뜨면 다 된 거예요.

5. **pandas로 옮기기**<br>
   인구통계 컬럼은 전체를 가져오고, 텍스트는 5만 건만 뽑아서 따로 둘게요.

```python
   demo_cols = ["sex", "age", "marital_status", "military_status", "family_type",
                "housing_type", "education_level", "bachelors_field", "occupation",
                "district", "province", "country"]

   df = ds.select_columns(["uuid"] + demo_cols).to_pandas()          # 전체 100만 건
   sample = ds.shuffle(seed=42).select(range(50_000)).to_pandas()   # 텍스트 포함 5만 건

   df.shape, sample.shape
```
