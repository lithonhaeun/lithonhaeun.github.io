이번 글에서는 NVIDIA가 공개한 한국어 합성 페르소나 데이터셋 Nemotron-Personas-Korea로 EDA(탐색적 데이터 분석)를 해보려고 한다. 이번 1편에서는 Mac에서 PyCharm으로 분석 환경을 만들고 데이터를 불러오는 과정까지 정리합니다.

먼저 EDA란? ~ 이다.

그리고 제가 분석하고자 하는 데이터는 ~ 입.
데이터분석을 위해서는 PyCharm을 사용할 겁니다.

### 1. PyCharm 세팅
1. PyCharm 아래쪽 Terminal에서 가상환경을 켜고
    ~~~
   source .venv/bin/activate
   ~~~
   >💡 가상환경(venv)을 쓰는 이유
프로젝트마다 패키지를 따로 관리할 수 있어서, 다른 프로젝트와 버전이 꼬이지 않는다.
2. 프롬포트 옆에 (.venv)가 나온걸확인 후 설치를 진행하였다.
    ~~~
   python -m pip install jupyter datasets pandas pyarrow matplotlib seaborn
   ~~~
3. PyCharm에서 주피터 노트북 쓰기
   ![](/assets/img/20260925-capture-2.png)
   프로젝트 폴더에서 오른쪽 클릭해 사진처럼 Jupyter notebook을 만들어주고
   <br><br>
   ![](/assets/img/20260925-capture-3.png)
   짠 저는 노트북 이름을 'people'이라 했어요<br>
   그리고 코드를 쳐서 제대로 됬는지 확인합니다.
   ~~~
   import sys
   print(sys.executable)
   ~~~
   ![](/assets/img/20260925-capture-4.png)
   이렇게 되면 완료!<br><br>
4. 이제 데이터를 불러오려고 합니다. 저는 MAC 환경이라 한글 설정좀 할게요.<br>
    ~~~
   import pandas as pd
   import matplotlib.pyplot as plt
   import seaborn as sns
   from datasets import load_dataset

   # Mac 한글 폰트 설정
   plt.rcParams["font.family"] = "AppleGothic"
   plt.rcParams["axes.unicode_minus"] = False

   # 데이터 불러오기 
   ds = load_dataset("nvidia/Nemotron-Personas-Korea", split="train")
   ds
   ~~~
   ![](/assets/img/20260925-capture-5.png)
