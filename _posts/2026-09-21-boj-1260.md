## 문제

그래프를 DFS와 BFS로 탐색한 결과를 출력하는 문제예요. 방문할 수 있는 정점이 여러 개면 **번호가 작은 것부터** 방문해요.

## 풀이 포인트

- 인접 리스트를 만든 뒤 각 리스트를 **정렬**해 두면 작은 번호부터 방문할 수 있어요.
- DFS는 재귀, BFS는 `deque`로 구현했어요.

## 코드

```python
import sys
from collections import deque
input = sys.stdin.readline

n, m, v = map(int, input().split())
graph = [[] for _ in range(n + 1)]
for _ in range(m):
    a, b = map(int, input().split())
    graph[a].append(b)
    graph[b].append(a)
for g in graph:
    g.sort()

def dfs(x, seen, out):
    seen[x] = True
    out.append(x)
    for y in graph[x]:
        if not seen[y]:
            dfs(y, seen, out)

def bfs(x):
    seen = [False] * (n + 1)
    seen[x] = True
    q, out = deque([x]), []
    while q:
        cur = q.popleft()
        out.append(cur)
        for y in graph[cur]:
            if not seen[y]:
                seen[y] = True
                q.append(y)
    return out

d = []
dfs(v, [False] * (n + 1), d)
print(*d)
print(*bfs(v))
```
