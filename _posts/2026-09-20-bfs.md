## 개념

**BFS(Breadth-First Search)** 는 시작 노드에서 가까운 노드부터 차례대로 방문하는 그래프 탐색 방법이에요. 큐(Queue)를 사용하고, 가중치가 없는 그래프에서 **최단 거리**를 구할 때 자주 써요.

## 동작 순서

1. 시작 노드를 큐에 넣고 방문 표시를 해요.
2. 큐에서 노드를 하나 꺼내요.
3. 그 노드와 연결된 노드 중 방문하지 않은 노드를 모두 큐에 넣고 방문 표시를 해요.
4. 큐가 빌 때까지 2~3을 반복해요.

## 파이썬 구현

```python
from collections import deque

def bfs(graph, start):
    visited = [False] * len(graph)
    queue = deque([start])
    visited[start] = True
    order = []

    while queue:
        node = queue.popleft()
        order.append(node)
        for nxt in graph[node]:
            if not visited[nxt]:
                visited[nxt] = True
                queue.append(nxt)
    return order
```

## 시간 복잡도

인접 리스트를 쓰면 `O(V + E)` 예요. (V: 노드 수, E: 간선 수)
